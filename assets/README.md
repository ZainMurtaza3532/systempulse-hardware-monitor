# Assets Directory

This directory is reserved for application assets:
- **Fonts**: TTF/OTF custom fonts (e.g., *Inter*, *JetBrains Mono*, *Roboto*).
- **Icons**: Icon font glyphs (e.g., *FontAwesome*, *Material Icons*).
- **Images**: Application icons, branding logos.

During build, CMake automatically deploys the contents of this directory next to the output binary in `bin/assets/`.
